# SQL_game_analytics
## Курсовая работа по модулю обучения основам SQL
____
**Цель работы** - оценить динамику пользовательской базы, активность игроков, финансовые результаты, собрать результаты технических заданий в единую структуру

**Легенда:** на протяжении нескольких месяцев я анализировала игру Zombie Revolution, ее популярность и монетезацию.
Ожидаемый результат - кратно и информативно рассказать менеджерам какие у игры метрики и какие результаты показали маркетинговые активности

*Что делала:*

  *Изучила исходные данные по количеству игроков, количеству сессий, средней длине сессий.
  
  *Расчитала долю проблемных записей для каждого типа устройства,процент проблемных записей Android, iOS.

  *Расчитала вирусность игры и средний размер будущих когорт.
  
  *Оценила изменеие метрик MAU, DAU, WAU, Sticky Factor.
  
  *Проанализировала динамику выручки и влияние маркетинговой акции на финансовые показатели.
      
  *Расчитала долю лояльных пользователей, протестировав разные критерии определения лояльности.

**Формат курсовой** - PowerPoint. Было необходимо представить видео с защитой, презентацию, по которой проводилась защита

Используемые инструменты ***PostgreSQL*** (case when, Join-ы, агрегации, CTE/подзапросы), Excel (постобработка, визуализация):
```SQL
select count (*) as cnt
	, count (id_user) as cnt_reg
	, count (distinct id_user) as cnt_user
from skygame.users
```
